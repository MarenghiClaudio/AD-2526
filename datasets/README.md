# Datasets

Cartella montata su `/data` dentro il container `data_loader`. Inserire qui i file di dataset.

## twitter_combined.txt

Dataset SNAP Twitter Social Circles (https://snap.stanford.edu/data/ego-Twitter.html).

Posizione attesa: `datasets/twitter_combined.txt`

Esempio:
```
214328887 34428380
17116707  28465635
...
```

Una riga per arco `follower_id followed_id` separati da spazio.
